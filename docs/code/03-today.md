# 3. Экран «Сегодня»

[src/app/(tabs)/index.tsx](../../src/app/(tabs)/index.tsx), [src/hooks/use-today.ts](../../src/hooks/use-today.ts)

## Где на экране

Первая вкладка: «Сегодня, вторник 13 октября», полоска недели, кольцо «60%, 3 из 5», список
привычек и круглая кнопка «+» внизу справа.

## Что делает

- Показывает выбранный день (по умолчанию — сегодня) и привычки, запланированные на него.
- Считает итог дня и серии — чистыми функциями, ничего не храня.
- Отмечает привычку нажатием или смахиванием, с разной вибрацией для «+1» и «выполнено».
- Переключает день по полоске недели; «Сегодня» — вернуться.
- Сам замечает наступление нового дня, даже если приложение не закрывали.
- Пустые состояния: «Пока нет привычек» и «На этот день ничего не запланировано».

## Код по частям

### Данные — из хранилища, всё остальное — вычисляется

```tsx
const today = useToday()
const habits = useStore((s) => s.habits)
const log = useStore((s) => s.log)
const tapHabit = useStore((s) => s.tapHabit)

const [picked, setPicked] = useState<DayKey | null>(null)
const day = picked ?? today

const planned = habitsFor(habits, day)
const summary = daySummary(habits, log, day)
const allDone = summary.planned > 0 && summary.done === summary.planned
```

**В состоянии компонента — только выбранный день.** «Кто запланирован», «какой процент», «какая
серия» — не хранятся, а считаются из `habits` и `log` на каждом рендере. Хранить их отдельно —
значит следить, чтобы копии не разошлись с оригиналом. Считать дёшево: привычек десятки.

**`picked` — `null`, а не сегодняшняя дата.** `null` значит «следим за сегодняшним днём». Наступила
полночь — `today` сменился, и экран сам показал новый день. Если бы мы сохранили в `picked`
строку `'2026-10-13'`, экран навсегда застрял бы на вчера.

### «Сегодня», которое меняется само

```ts
export function useToday(): DayKey {
  const [today, setToday] = useState(() => toKey(new Date()))
  useEffect(() => {
    const refresh = () => setToday(toKey(new Date()))
    const subscription = AppState.addEventListener('change', (state) => {
      if (state === 'active') refresh()
    })
    const timer = setInterval(refresh, 60_000)
    return () => { subscription.remove(); clearInterval(timer) }
  }, [])
  return today
}
```

Мобильное приложение живёт днями: его сворачивают вечером и разворачивают утром **без
перезапуска**. Два способа заметить новый день:

- `AppState` → `'active'` — приложение вернулось на экран;
- раз в минуту — чтобы поймать полночь, если человек смотрит на экран.

`setToday` с той же строкой не вызывает перерисовку — React сравнивает значения сам, проверять
«изменилось ли» не нужно.

### Нажатие с отзывом

```tsx
const toggle = (id: string, target: number) => {
  const next = tapHabit(id, day)
  if (next >= target) haptic.success()
  else haptic.tap()
}
```

Разная вибрация для «+1 стакан» и «привычка выполнена» — пальцем чувствуется, что цель
достигнута, даже не глядя на экран.

### Список

```tsx
{planned.map((habit) => (
  <HabitCard
    key={habit.id}
    habit={habit}
    count={countOn(log, habit, day)}
    streak={currentStreak(habit, log, today)}
    onToggle={() => toggle(habit.id, habit.target)}
    onEdit={() => router.push(`/habit/${habit.id}`)}
  />
))}
```

- Отметки — за **выбранный** день (`day`), а серия — от **сегодня** (`today`): серия — это про
  «сейчас», а не про день, который вы листаете.
- Карточка «глупая»: получает числа и колбэки, ничего не знает про хранилище (страница 4).
- Список обычным `map` в `ScrollView`, а не `FlatList`: привычек десятки. `FlatList` нужен для сотен
  и тысяч строк — он рисует только видимые.

### Плавающая кнопка

```tsx
<Pressable accessibilityRole="button" accessibilityLabel="Добавить привычку"
  onPress={() => router.push('/habit/new')} style={…}>
  <Ionicons name="add" size={30} />
</Pressable>
```

Главное действие — под большим пальцем, внизу справа. У значка без текста обязательно
`accessibilityLabel` — иначе VoiceOver скажет «кнопка». `paddingBottom: 110` у списка — чтобы
кнопка не закрывала последнюю карточку.

## Что будет, если…

| Сделать | Что сломается |
| --- | --- |
| `useState(toKey(new Date()))` без `useToday` | утром приложение показывает вчерашний день |
| `picked` = дата сегодня по умолчанию | после полуночи экран не переключается на новый день |
| хранить `summary` в `useState` | после отметки процент не обновится, пока не вспомнят пересчитать |
| серия от `day` | при пролистывании на прошлую неделю «🔥» показывает другое число |

## Проверьте себя

1. Почему нет `useEffect`, который пересчитывает `summary` при изменении `log`?
2. Откройте приложение, выберите вчерашний день и подождите до полуночи. Что покажет экран?

<details>
<summary>Ответы</summary>

1. `summary` вычисляется прямо в рендере. Изменился `log` — компонент перерисовался — значение
   новое. Эффект только добавил бы лишний рендер.
2. По-прежнему выбранный вчерашний (уже позавчерашний) день: `picked` хранит конкретную дату.
   «Следить за сегодня» — это `picked === null`.
