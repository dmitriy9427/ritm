# Разбор кода: файл за файлом

Главы учебника объясняют **идеи**: потоки, жесты, хранилище, даты. Здесь — **конкретный код**:
ключевые файлы «Ритма» порциями, после каждой — что она делает и зачем.

## Как устроена каждая страница

1. **Где на экране** — что видит человек.
2. **Что делает** — по пунктам.
3. **Пропсы и пример** — как пользоваться.
4. **Код по частям** — настоящий код с объяснением.
5. **Что будет, если…** — уберите строку и посмотрите, что сломается.
6. **Проверьте себя** — вопросы с ответами.
