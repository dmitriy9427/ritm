# Уроки: найденные баги

Восемь ошибок, пойманных при разработке «Ритма». У каждой — что было видно, в чём причина,
как исправлено и что вынести. Половина из них — про разницу между «прочитал в статье» и
«так устроена текущая версия».

## 1. `StyleSheet.absoluteFillObject` больше нет

**Видно:** ошибка типов — свойства не существует.

**Причина:** во всех старых примерах «растянуть на родителя» пишут
`...StyleSheet.absoluteFillObject`. В новых версиях React Native его убрали.

**Исправление:** написать явно.

```ts
center: { position: 'absolute', top: 0, right: 0, bottom: 0, left: 0 }
```

**Урок:** React Native меняется быстро, а статьи и ответы живут годами. Источник правды —
документация **вашей** версии и типы в `node_modules`, а не поиск.

## 2. `Tabs` переехали в `expo-router/js-tabs`

**Видно:** предупреждение об устаревшем импорте `Tabs` из корня `expo-router`.

**Причина:** в Expo Router появились нативные вкладки, и JS-вкладки вынесли в отдельную
точку входа. `Stack` — аналогично, в `expo-router/stack`.

**Исправление:** `import { Tabs } from 'expo-router/js-tabs'`.

**Урок:** предупреждения об устаревании читают и исправляют сразу: в следующем SDK это уже
ошибка, и чинить её придётся вместе с десятком других.

## 3. Dev-сервер с `CI=1` не следит за файлами

**Видно:** правлю код, обновляю страницу — в браузере старая версия. Полчаса поисков
«почему исправление не помогло».

**Причина:** сервер был запущен с переменной `CI=1` (чтобы не задавал вопросов в
терминале). В этом режиме Metro **отключает слежение за файлами** — собирает один раз.

**Исправление:** запуск без `CI`, обычным `npx expo start`.

**Урок:** если правка «не работает» — первым делом убедиться, что она **дошла**: поставить
`console.log('v2')` или заметно поменять цвет. Отлаживать код, который не выполняется,
можно бесконечно.

## 4. Клик после свайпа снимал отметку (только в браузере)

**Видно:** на вебе смахиваю карточку — отметка ставится и тут же снимается.

**Причина:** на телефоне начавшийся жест отменяет нажатие. В браузере после отпускания мыши
приходит ещё и обычный `click` — срабатывали оба: жест отметил, клик снял.

**Исправление:** флажок «только что смахивали», который сбрасывается через 250 мс после
конца жеста; обработчик нажатия его проверяет.

```ts
.onStart(() => { swiped.value = 1; })
.onFinalize(() => { swiped.value = withDelay(250, withTiming(0, { duration: 0 })); })

const press = () => { if (swiped.value > 0) return; onToggle(); };
```

**Урок:** «один код на три платформы» — про код, а не про поведение. Жесты, клавиатуру,
диалоги и прокрутку нужно проверять на **каждой** платформе.

## 5. `ref` в рендере и React Compiler

**Видно:** первая версия флажка из п. 4 была на `useRef` — линтер (`react-hooks/refs`)
запретил читать `ref.current` во время рендера.

**Причина:** в проекте включён React Compiler (`"reactCompiler": true`): он сам мемоизирует
компоненты и для этого должен быть уверен, что рендер — чистая функция. Чтение изменяемого
`ref` это нарушает. К тому же флажок меняет жест в UI-потоке, куда обычный `ref` не попадает.

**Исправление:** shared value — значение, которое по замыслу живёт в обоих потоках.

**Урок:** правило линтера — подсказка об устройстве инструмента. Вместо
`// eslint-disable` стоит спросить «что он пытается мне сказать» — здесь он привёл к
более правильному решению.

## 6. Обрезанные подписи вкладок

**Видно:** на телефоне с полоской жестов подписи «Сегодня / Статистика» срезаны снизу.

**Причина:** высота панели была задана числом и не учитывала нижнюю безопасную зону.

**Исправление:**

```ts
const { bottom } = useSafeAreaInsets();
tabBarStyle: { height: 66 + bottom, paddingBottom: bottom + 6 }
```

**Урок:** фиксированная высота + безопасная зона = обрезка на каком-то из устройств.
Проверять минимум на двух: с «чёлкой» и полоской жестов и без них.

## 7. `textTransform: 'capitalize'` поднимает каждое слово

**Видно:** заголовок «Понедельник, 13 Октября» — месяц с заглавной.

**Причина:** `capitalize` (как и в CSS) делает заглавной первую букву **каждого** слова.
Для русского текста это ошибка.

**Исправление:** функция в коде: `text[0].toUpperCase() + text.slice(1)`.

**Урок:** оформление текста, зависящее от языка, — в коде, а не в стилях. Туда же —
склонения (`plural`) и форматы дат.

## 8. Типы Jest не подхватились

**Видно:** `tsc` ругается на `describe`, `it`, `expect` в тестах, хотя тесты проходят.

**Причина:** Jest сам запускает тесты и знает свои глобальные функции. TypeScript — нет:
в `tsconfig.json` не были подключены типы.

**Исправление:** `"types": ["jest"]` в `compilerOptions`.

**Урок:** «тесты зелёные» и «типы зелёные» — две разные проверки. Поэтому есть
`npm run check`, который запускает линтер, типы и тесты вместе — и он же работает в CI.
