# Шпаргалка к собеседованию

Короткие ответы своими словами. Где возможно — со ссылкой на место в проекте: «я это делал»
звучит убедительнее, чем «я это читал».

## Основы

**Что такое React Native?**
Библиотека для мобильных приложений на React. Компоненты описываются на JS/TS, а на экране
— настоящие нативные элементы платформы (`UIView`, `android.view.View`), а не веб-страница
в обёртке.

**Чем отличается от веб-приложения в WebView (Cordova, Ionic)?**
Там интерфейс рисует браузерный движок внутри приложения. В RN интерфейс нативный:
системная прокрутка, жесты, доступность, производительность.

**А от Flutter?**
Flutter рисует всё сам на своём движке (язык Dart). RN использует системные компоненты и
экосистему JS/React.

**Что такое Expo?**
Фреймворк и набор инструментов поверх RN: готовые нативные модули (`expo-*`), файловая
навигация (Expo Router), Expo Go для запуска на телефоне, облачная сборка EAS. Сегодня это
рекомендуемый способ начать проект на React Native.

**Expo Go и development build — в чём разница?**
Expo Go — готовое приложение с фиксированным набором нативных модулей: мой JS загружается в
него. Development build — такое же, но собранное из моего проекта, с любыми нативными
модулями. «Ритму» хватает Expo Go.

**Что такое новая архитектура?**
JSI вместо старого «моста»: JS вызывает нативный код напрямую, без сериализации в JSON.
Fabric — новый рендерер, TurboModules — ленивая загрузка нативных модулей. В актуальных
версиях включена по умолчанию.

**Какие потоки есть в приложении?**
JS-поток (моя логика и React) и UI-поток (отрисовка, касания). Если JS занят, интерфейс
может не реагировать — поэтому анимации и жесты выносят в UI-поток (Reanimated).

## Вёрстка

**Чем стили отличаются от CSS?**
Объекты вместо файлов, нет каскада и наследования (кроме `Text` в `Text`), только flexbox,
`flexDirection` по умолчанию `column`, размеры — числа в независимых от плотности точках.

**Как сделать адаптивность без media queries?**
`flex`, проценты, `useWindowDimensions()`, `aspectRatio`, ограничение `maxWidth`.

**Что такое безопасные зоны?**
Области экрана под вырезом, статус-баром и полоской жестов. `react-native-safe-area-context`:
`SafeAreaView` или `useSafeAreaInsets()`. В проекте — экраны и высота панели вкладок.

**`ScrollView` или `FlatList`?**
`ScrollView` рисует всё содержимое сразу — для коротких экранов. `FlatList` виртуализирует:
создаёт только видимые строки — для длинных списков. Нужны `keyExtractor` и лёгкий
`renderItem`.

**Как сделать тёмную тему?**
`useColorScheme()` + объект с двумя наборами цветов + хук `useTheme()`. В `app.json` —
`"userInterfaceStyle": "automatic"`. Навигатору тема передаётся отдельно, иначе при
переходах белая вспышка.

**Как учесть клавиатуру?**
`KeyboardAvoidingView` (`behavior="padding"` на iOS), `keyboardShouldPersistTaps="handled"`
у `ScrollView`.

## Навигация

**Как устроена навигация?**
Не адреса, а навигаторы: Stack (стопка экранов), Tabs (вкладки), модальные окна. Expo Router
строит их из файлов в `app/`; под капотом — React Navigation.

**Что такое deep link?**
Ссылка, открывающая конкретный экран приложения: `ritm://habit/abc`. В Expo Router каждый
экран уже имеет адрес, схема задаётся в `app.json`.

**Что передавать в параметрах экрана?**
Идентификатор, а не объект. Данные экран берёт из хранилища по id — они актуальны, и
работает прямая ссылка.

## Данные

**Где хранить данные на устройстве?**
AsyncStorage — настройки и небольшие данные (не зашифровано). SecureStore — токены и
пароли. SQLite — большие объёмы и запросы.

**Что такое гидрация хранилища и чем она опасна?**
Чтение сохранённого состояния с диска асинхронное: первый рендер идёт с начальными
значениями. Без флага готовности — мигание пустого экрана и риск перезаписать данные
«инициализацией». В проекте — `hydrated`.

**Как менять структуру сохранённых данных?**
Версия + миграция (`version`, `migrate` в `persist`). У пользователей остаются данные
старого вида, чистить хранилище нельзя.

**Почему день хранится строкой, а не `Date`?**
`toISOString()` даёт дату в UTC — ночью это другой день. Строка `YYYY-MM-DD` в местном
времени однозначна, сравнивается как дата и служит ключом словаря. Арифметика — через
`setDate`, а не «плюс 24 часа» (переход на летнее время).

**Как приложение узнаёт, что наступил новый день?**
Его не перезапускают — сворачивают. `AppState` (вернулось на экран) + таймер.
`use-today.ts`.

## Анимации и жесты

**Почему Reanimated, а не `Animated` или `setState`?**
Анимация выполняется в UI-потоке и не зависит от загрузки JS. `setState` на каждый кадр —
перерисовка через React.

**Что такое shared value и ворклет?**
Shared value — значение, доступное обоим потокам; его изменение не вызывает рендер.
Ворклет — функция, выполняемая в UI-потоке (`useAnimatedStyle`, обработчики жестов). Из
ворклета в JS — через `scheduleOnRN`.

**Как сделать свайп элемента внутри прокручиваемого списка?**
`Gesture.Pan()` с `activeOffsetX` и `failOffsetY`: жест включается только при
горизонтальном движении, вертикальное остаётся прокрутке. Возврат на место — в
`onFinalize` (вызывается и при отмене жеста).

**Какие свойства анимировать?**
`transform` и `opacity` — не требуют пересчёта вёрстки.

## Возможности устройства

**Локальные и push-уведомления — в чём разница?**
Локальные планирует приложение на устройстве, сервер не нужен. Push отправляет сервер через
APNs/FCM — нужны бэкенд, токен устройства и своя сборка.

**Когда запрашивать разрешения?**
В момент, когда пользователь включает функцию и понимает зачем. На iOS системный диалог
показывается один раз; после отказа — только через настройки системы. Отказ не должен
ломать приложение.

**Как писать платформенный код?**
`Platform.OS`, `Platform.select`, файлы `.ios.tsx / .android.tsx / .web.tsx`. В проекте
всё платформенное собрано в `src/platform/` за общим интерфейсом.

## Качество и выпуск

**Что и как тестировать?**
Логику — Jest, чистые функции без устройства (в проекте 30 тестов: даты, серии,
расписание). Компоненты — React Native Testing Library. Сценарии целиком — Maestro или Detox.

**Как приложение попадает к пользователю?**
EAS Build собирает `.ipa` / `.aab` в облаке (iOS — без Mac), EAS Submit отправляет в App
Store и Google Play. Нужны платные аккаунты разработчика.

**Что такое OTA-обновления?**
Доставка JS-части приложения напрямую на устройства (`expo-updates`), минуя магазин. Нативные
изменения так не доставить.

**Что такое prebuild / CNG?**
Папки `ios/` и `android/` генерируются из `app.json` и плагинов, а не хранятся в
репозитории. Обновление SDK не требует ручного слияния нативных проектов.

**Как следить за производительностью?**
Не делать лишних рендеров (узкие селекторы хранилища, React Compiler), длинные списки —
`FlatList`, анимации — в UI-потоке, картинки нужного размера, тяжёлое — не в рендере.

## Про проект — рассказ на минуту

«Трекер привычек на Expo и React Native: один код для iOS, Android и браузера. Три экрана на
вкладках и модальная форма (Expo Router). Данные хранятся на устройстве — Zustand с
сохранением в AsyncStorage, с версией данных и ожиданием гидрации. Логика серий и
статистики — чистые функции с тестами. Отметка свайпом — Gesture Handler и Reanimated в
UI-потоке; кольцо прогресса — анимированный SVG. Напоминания — локальные уведомления с
запросом разрешения. Веб-версия собирается и публикуется на GitHub Pages через Actions после
линтера, проверки типов и тестов.»
