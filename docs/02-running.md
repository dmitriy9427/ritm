# 02. Запуск

## На своём телефоне (Expo Go) — без Xcode

1. Установите **Expo Go** из App Store или Google Play.
2. В папке проекта:

```bash
npm install
```

```bash
npm start
```

3. В терминале появится QR-код.
   - **iPhone:** наведите обычную камеру, нажмите на ссылку.
   - **Android:** откройте Expo Go → «Scan QR code».
4. Телефон и компьютер должны быть **в одной сети Wi-Fi**. Не видит (гостевая сеть, VPN,
   офисный файрвол) — запустите через туннель:

```bash
npx expo start --tunnel
```

Сохранили файл — приложение на телефоне обновилось за секунду (*Fast Refresh*), состояние
экрана сохраняется. Встряхните телефон — откроется меню разработчика (перезагрузка,
инспектор элементов).

## В браузере

```bash
npm run web
```

Откроется http://localhost:8081 — то же приложение на `react-native-web`. Удобно для
быстрой проверки вёрстки и логики; вибрации и уведомлений в браузере нет.

## В симуляторе / эмуляторе (по желанию)

| Платформа | Что установить | Команда |
| --- | --- | --- |
| iOS (только на Mac) | Xcode из App Store (~15 ГБ), открыть один раз, согласиться с лицензией | `npm run ios` |
| Android | Android Studio, создать виртуальное устройство (AVD) | `npm run android` |

Симулятор нужен, чтобы проверять разные размеры экранов и версии системы, не имея
устройств. Для учёбы хватает своего телефона.

## Проверки

```bash
npm run check
```

Линтер (`expo lint`) → типы (`tsc`) → тесты (`jest`). Запускайте перед каждым коммитом.

## Структура проекта

```
ritm/
├── app.json            настройки приложения: имя, иконки, плагины, разрешения
├── app.config.js       то, что зависит от окружения (путь сайта на GitHub Pages)
├── assets/images/      иконка, заставка, favicon
└── src/
    ├── app/                    ЭКРАНЫ — каждый файл здесь = адрес (Expo Router)
    │   ├── _layout.tsx         корень: стопка экранов, тема, жесты
    │   ├── (tabs)/
    │   │   ├── _layout.tsx     нижние вкладки
    │   │   ├── index.tsx       «Сегодня»
    │   │   ├── stats.tsx       «Статистика»
    │   │   └── settings.tsx    «Настройки»
    │   └── habit/[id].tsx      форма привычки (модальное окно)
    ├── components/             кирпичики интерфейса
    │   ├── ui.tsx              текст, экран, карточка, кнопки
    │   ├── habit-card.tsx      карточка со свайпом
    │   ├── progress-ring.tsx   кольцо на SVG
    │   ├── week-strip.tsx      полоска недели
    │   └── charts.tsx          столбики и «тепловая карта»
    ├── lib/                    ЧИСТАЯ ЛОГИКА без React (с тестами)
    │   ├── dates.ts            даты-строки, склонения
    │   ├── habits.ts           расписание, серии, статистика
    │   └── seed.ts             демо-данные
    ├── store/store.ts          состояние + сохранение на устройстве
    ├── platform/               всё, что зависит от платформы
    │   ├── haptics.ts          вибрация
    │   ├── notifications.ts    напоминания
    │   └── confirm.ts          диалог подтверждения
    ├── hooks/                  use-theme, use-today
    └── constants/theme.ts      цвета, отступы, скругления
```

Правило слоёв — такое же, как в остальных проектах портфолио:

```
экраны (app/)  →  компоненты  →  store  →  lib (чистые функции)
                      ↓
                  platform (вибрация, уведомления)
```

`lib/` ничего не знает про React и телефон — поэтому покрывается тестами без эмуляторов.

## Если что-то не работает

| Симптом | Что сделать |
| --- | --- |
| Правки не появляются | Перезапустить с очисткой кеша: `npx expo start --clear` |
| «Network response timed out» на телефоне | Разные сети Wi-Fi → `npx expo start --tunnel` |
| Ошибка про несовместимые версии пакетов | `npx expo install --fix`, затем `npx expo-doctor` |
| Красный экран с ошибкой | Прочитать первую строку и стек — там файл и строка; после исправления сохранить файл |
| В CI/скрипте сервер не видит изменений | Переменная `CI=1` выключает слежение за файлами (см. [lessons.md](lessons.md)) |
