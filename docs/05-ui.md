# 05. Интерфейс: вёрстка, тема, безопасные зоны, доступность

## Свои базовые компоненты (`src/components/ui.tsx`)

В RN нет глобальных стилей: у `<Text>` нет размера «по умолчанию для заголовка», у кнопки
нет вида. Поэтому первым делом пишутся свои кирпичики:

| Компонент | Что делает |
| --- | --- |
| `AppText` | текст с вариантом (`title`, `heading`, `body`, `small`, `caption`) и цветом темы |
| `Screen` | фон, безопасная зона сверху, ограничение ширины |
| `Card` | подложка со скруглением и рамкой |
| `Button`, `IconButton` | нажимаемые элементы с откликом и подписью для скринридера |

После этого в экранах нет ни одного «сырого» размера шрифта — только `variant="heading"`.

## Тема (`src/constants/theme.ts`, `src/hooks/use-theme.ts`)

```ts
export const Colors = {
  light: { background: '#F4F5F7', card: '#FFFFFF', text: '#14161B', accent: '#14B87A', … },
  dark:  { background: '#0D0F12', card: '#181B20', text: '#F2F4F7', accent: '#2FD18F', … },
};
```

```tsx
const theme = useTheme();
<View style={[styles.card, { backgroundColor: theme.card, borderColor: theme.border }]} />
```

`useTheme()` выбирает набор по системной теме (`useColorScheme()` из React Native — обновляется
сам, когда тема телефона меняется) или по настройке приложения. Постоянная часть стиля
(размеры, отступы) — в `StyleSheet`, цвет — объектом рядом.

Отступы и скругления тоже из констант: `Spacing[4]` = 16, `Radius.lg` = 16. Шаг сетки — 4.

## Безопасные зоны

У телефонов есть вырезы: «чёлка» и статус-бар сверху, полоска жестов снизу, скруглённые
углы. Содержимое не должно под них попадать.

```tsx
import { SafeAreaView, useSafeAreaInsets } from 'react-native-safe-area-context';

// Экран: отступаем сверху и по бокам (низ занят панелью вкладок)
<SafeAreaView edges={['top', 'left', 'right']} style={{ flex: 1 }}>

// Панель вкладок: её высота учитывает полоску жестов
const { bottom } = useSafeAreaInsets();   // iPhone без кнопки — ~34, Android/веб — 0
tabBarStyle: { height: 66 + bottom, paddingBottom: bottom + 6 }
```

Это не украшение: без `bottom` подписи вкладок либо залезают под полоску жестов, либо
обрезаются (такая ошибка была — [lessons.md](lessons.md)).

## Размер экрана и ширина

Телефоны разные, а приложение открывают ещё на планшете и в браузере. `Screen` ограничивает
содержимое (`maxWidth: 560`, `alignSelf: 'center'`), внутри всё на `flex` и процентах — без
фиксированных ширин. Клетки «тепловой карты» квадратные при любой ширине благодаря
`aspectRatio: 1`.

## Область нажатия

Палец — не курсор. Минимальный размер нажимаемого элемента — **44×44** (Apple) / 48×48
(Google). В проекте это константа `HitSize`. Если видимая иконка меньше — область
расширяет `hitSlop`:

```tsx
<Pressable hitSlop={8} style={{ width: 44, height: 44 }}>
```

Отклик на нажатие обязателен (на телефоне нет курсора-«руки»):

```tsx
<Pressable style={({ pressed }) => [styles.button, pressed && { opacity: 0.6 }]}>
```

## Прокрутка

```tsx
<ScrollView
  contentContainerStyle={styles.scroll}        // отступы — у содержимого, не у самого ScrollView
  showsVerticalScrollIndicator={false}
  keyboardShouldPersistTaps="handled">         // нажатие на кнопку при открытой клавиатуре срабатывает сразу
```

`ScrollView` рисует всё содержимое сразу — для десятка привычек это нормально. Для длинных
списков (сотни строк) берут `FlatList`: он создаёт только видимые строки.

Плавающая кнопка «+» — `position: 'absolute'` у элемента **вне** `ScrollView`; у списка
`paddingBottom: 110`, чтобы кнопка не закрывала последнюю карточку.

## Клавиатура

Экранная клавиатура закрывает нижнюю половину экрана — и поле, в которое вы печатаете.

```tsx
<KeyboardAvoidingView behavior={Platform.OS === 'ios' ? 'padding' : undefined} style={{ flex: 1 }}>
```

На iOS контейнер сжимается на высоту клавиатуры; на Android система сама двигает окно.
Полезные свойства `TextInput`: `autoFocus`, `returnKeyType="done"`, `keyboardType`,
`maxLength`, `autoCapitalize`.

## Форма (`src/app/habit/[id].tsx`)

- **Черновик — локальное состояние** экрана. В хранилище он попадает только по «Сохранить»:
  закрыли окно — ничего не изменилось.
- **Ошибки показываются после первой попытки сохранить** (`submitted`), а не пока человек
  ещё печатает.
- **Нормализация при сохранении**: `trim()`, сортировка дней, время `9:05` → `09:05` — в
  хранилище один формат.
- Библиотека форм не нужна: полей мало. В большом проекте — React Hook Form, он работает и
  в RN.

## Доступность

Скринридеры — VoiceOver (iOS) и TalkBack (Android) — читают экран вслух. HTML-семантики
нет, поэтому роль и подпись задаются свойствами:

| Свойство | Зачем | Пример из проекта |
| --- | --- | --- |
| `accessibilityRole` | что это: `button`, `checkbox`, `radio`, `image` | кнопки, дни недели, переключатель темы |
| `accessibilityLabel` | что прочитать | карточка: «Зарядка. Выполнено. Серия 6 дней» |
| `accessibilityHint` | что произойдёт | «Нажмите, чтобы отметить. Долгое нажатие — изменить» |
| `accessibilityState` | состояние: `checked`, `selected`, `disabled` | отмеченная привычка, выбранный день |
| `accessibilityLiveRegion` | зачитать появившийся текст | ошибка формы |

Правила:

- у кнопки-иконки **обязателен** `accessibilityLabel` (в `IconButton` это обязательный проп);
- график без подписи — «картинка без alt»: у `BarChart` и `Heatmap` есть текстовое описание;
- размер шрифта системы учитывается сам — не задавайте фиксированную высоту контейнерам с
  текстом;
- цвет не единственный носитель смысла: выполненная привычка ещё и зачёркнута, и с галочкой.

Проверить на устройстве: iOS — Настройки → Универсальный доступ → VoiceOver; Android —
Настройки → Спец. возможности → TalkBack.

## Ошибки

> **Контент под вырезом камеры** или под полоской «домой». Корень экрана — в безопасной зоне
> (`Screen` в `ui.tsx`).
>
> **Клавиатура закрыла поле ввода.** Нужен `KeyboardAvoidingView` или прокрутка с
> `keyboardShouldPersistTaps`.
>
> **Кнопка-значок 20×20.** Пальцу нужно минимум ~44 точки: `hitSlop` или своя `HitSize`.
>
> **Нет `accessibilityLabel` у карточки.** VoiceOver прочитает набор надписей подряд без смысла.
> В «Ритме» у карточки одна понятная фраза: название, прогресс, серия.
