# 07. Анимации и жесты

## Почему не `setState` и не CSS

CSS-переходов в RN нет. А анимация через `setState` на каждый кадр идёт длинным путём:
JS-поток считает → React сравнивает → изменения отправляются в нативный слой. Если JS в этот
момент занят (пересчёт списка, сетевой ответ), кадры пропускаются.

**Reanimated** выполняет анимацию в **UI-потоке** — том же, что рисует экран. JavaScript
может быть занят чем угодно: анимация идёт 60/120 кадров в секунду.

## Три кирпичика

```tsx
import Animated, { useSharedValue, useAnimatedStyle, withTiming } from 'react-native-reanimated';

const offset = useSharedValue(0);                       // 1. число, живущее вне рендера

const style = useAnimatedStyle(() => ({                 // 2. стиль, вычисляемый из числа
  transform: [{ translateX: offset.value }],
}));

offset.value = withTiming(100, { duration: 300 });      // 3. «плавно дойди до 100»

<Animated.View style={style} />                         // обычный View не анимируется
```

| | Обычное состояние | Shared value |
| --- | --- | --- |
| Изменение | перерисовывает компонент | **не** перерисовывает |
| Где живёт | JS-поток | оба потока |
| Для чего | данные, от которых зависит разметка | числа анимации: сдвиг, масштаб, прозрачность |

Функции анимации:

| Функция | Поведение | В проекте |
| --- | --- | --- |
| `withTiming(to, { duration, easing })` | за заданное время | кольцо прогресса, полоса счётчика |
| `withSpring(to, { damping, stiffness })` | пружина: длительность получается сама | возврат карточки, «прыжок» галочки |
| `withSequence(a, b)` | одна за другой | галочка: увеличиться → вернуться |
| `withDelay(ms, a)` | с задержкой | сброс флажка свайпа |
| `interpolate(v, [0, 84], [0, 1], 'clamp')` | пересчёт диапазона | сдвиг карточки → прозрачность подложки |

Пружина хороша для всего, что «трогают пальцем»: её можно прервать в любой момент, и
движение продолжится естественно с текущей скоростью.

## Ворклеты

Функция внутри `useAnimatedStyle` и обработчики жестов — **ворклеты**: они выполняются в
UI-потоке. Babel-плагин (в Expo подключён сам) копирует такую функцию в другой поток.
Следствия:

- внутри нельзя вызывать обычные JS-функции (изменить хранилище, `router.push`) — только
  через `scheduleOnRN(fn, …args)` из `react-native-worklets`: он передаёт вызов в JS-поток;
- читать и писать `sharedValue.value` — можно.

```tsx
.onEnd(() => {
  if (offset.value >= SWIPE_THRESHOLD) scheduleOnRN(onToggle);   // onToggle меняет хранилище
})
```

## Кольцо прогресса (`src/components/progress-ring.tsx`)

Приём тот же, что в вебе: у окружности штрих длиной в саму окружность
(`strokeDasharray = 2πr`), а `strokeDashoffset` сдвигает его — `длина × (1 − прогресс)`.

Отличие: анимируется не стиль, а **свойство** SVG-компонента.

```tsx
const AnimatedCircle = Animated.createAnimatedComponent(Circle);
const animatedProps = useAnimatedProps(() => ({ strokeDashoffset: length * (1 - value.value) }));

<AnimatedCircle strokeDasharray={length} animatedProps={animatedProps} … />
```

SVG поворачивается на −90°: окружность начинается справа («3 часа»), а прогресс должен идти
сверху.

## Свайп карточки (`src/components/habit-card.tsx`)

```tsx
const swipe = Gesture.Pan()
  .activeOffsetX(14)            // включиться только при движении ВПРАВО больше 14
  .failOffsetY([-12, 12])       // сдаться, если палец пошёл по вертикали
  .onUpdate((e) => { offset.value = Math.min(SWIPE_MAX, Math.max(0, e.translationX)); })
  .onEnd(() => { if (offset.value >= SWIPE_THRESHOLD) scheduleOnRN(onToggle); })
  .onFinalize(() => { offset.value = withSpring(0); });

<GestureDetector gesture={swipe}>
  <Animated.View style={cardStyle}>…</Animated.View>
</GestureDetector>
```

Разбор:

- **`activeOffsetX` / `failOffsetY` — главное для жеста внутри списка.** Карточки лежат в
  `ScrollView`. Без этих двух строк каждое касание карточки начинало бы жест, и список
  нельзя было бы прокрутить. Так вертикальное движение достаётся прокрутке, горизонтальное —
  карточке.
- **`onEnd` и `onFinalize` — разное.** `onEnd` — жест завершён пользователем. `onFinalize` —
  вызывается всегда, в том числе когда жест отменён (система перехватила касание, пришёл
  звонок). Возврат карточки на место — в `onFinalize`, иначе она может «застрять» сдвинутой.
- **Порог и предел**: сдвиг ограничен 120, отметка — от 84. Подложка проявляется по мере
  движения (`interpolate`), так что пользователь видит, «дотянул» ли.
- Корень приложения обёрнут в `GestureHandlerRootView` (`src/app/_layout.tsx`) — без него
  жесты не работают.

Свайп — **ускоритель, а не единственный способ**: то же делает обычное нажатие. Жест нельзя
обнаружить глазами и нельзя выполнить скринридером.

## Отклик на действие

Отметка привычки — это три сигнала сразу: галочка «подпрыгивает» (`withSequence`), кольцо
дня доезжает, телефон коротко вибрирует (глава 08). По отдельности мелочи, вместе —
ощущение «нативного» приложения.

## Правила хорошего тона

- Анимируйте `transform` и `opacity`: они не пересчитывают вёрстку. Анимация `width`/`height`
  дороже (в проекте — только короткая полоса счётчика).
- 150–450 мс. Дольше — интерфейс кажется медленным.
- «Уменьшить движение» — системная настройка; Reanimated даёт `useReducedMotion()`, чтобы
  отключать необязательные анимации.
- Для сложных готовых анимаций (конфетти, иллюстрации) — Lottie, а не сотня shared values.
