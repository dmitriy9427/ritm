# Учебник по «Ритму»

Для тех, кто знает React для веба и хочет понять мобильную разработку на React Native.
Читать по порядку, рядом открыв код: в каждом файле комментарии объясняют «почему так».

**Впервые здесь?** Начните с [00. С чего начать](00-start.md): что происходит, когда вы
смахиваете привычку, и словарь. В конце глав — частые ошибки и задания с ответами.

## Как учиться на этом проекте

1. **Запустите на своём телефоне** (глава 02) — пять минут, Xcode не нужен. Ощущение «мой код
   работает в руке» стоит больше любой теории.
2. **Поменяйте маленькое и посмотрите результат** — приложение обновляется на телефоне при
   сохранении файла:
   - цвет акцента — `Colors.light.accent` в `src/constants/theme.ts`;
   - список значков — `EMOJIS` в `src/app/habit/[id].tsx`;
   - порог свайпа — `SWIPE_THRESHOLD` в `src/components/habit-card.tsx`.
3. **Прочитайте главы 03–05** и откройте `src/app/(tabs)/index.tsx` — экран «Сегодня». В нём
   почти всё: список, состояние, навигация, вибрация.
4. **Добавьте фичу сами.** Идеи по возрастанию сложности:
   - заметка к привычке (поле в форме и подпись на карточке);
   - кнопка «−1» у счётной привычки;
   - сортировка привычек перетаскиванием;
   - экспорт данных в файл (expo-sharing);
   - виджет на домашний экран (нужна своя сборка, не Expo Go).
5. Запускайте `npm run check` — линтер, типы и 30 тестов подскажут, если что-то сломалось.
